# Тестирование API

## Общая информация

Все коллекции Postman находятся в папке [postman](../postman/):

- [CartCollection.postman_collection.json](../postman/CartCollection.postman_collection.json) — тестирование корзин;
- [ProductCollection.postman_collection.json](../postman/ProductCollection.postman_collection.json) — тестирование товаров.

Базовый URL API: `https://fakestoreapi.com`

В коллекциях проверяются основные CRUD-операции, корректные и некорректные параметры запросов, наличие обязательных полей и HTTP-статус ответа.

## Проверки товаров

Коллекция: `ProductCollection`

| Метод | Endpoint | Сценарии | Ожидаемый статус |
|---|---|---|---:|
| `GET` | `/products/` | Получение списка всех товаров | `200` |
| `GET` | `/products/1` | Получение первого товара | `200` |
| `GET` | `/products/20` | Получение последнего товара | `200` |
| `GET` | `/products/21` | Получение несуществующего товара | `200` |
| `POST` | `/products` | Создание нового товара с корректными данными | `201` |
| `POST` | `/products` | Некорректный тип `id`, `title`, `price`, `description`, `category` или `image` | `201`|
| `POST` | `/products` | Отсутствие `id`, `title`, `price`, `description`, `category` или `image` | `201` |
| `PUT` | `/products/1` | Полная замена существующего товара | `200` |
| `PUT` | `/products/1` | Замена товара пустым телом | `200`  |
| `PUT` | `/products/999` | Замена несуществующего товара | `200` |
| `DELETE` | `/products/1` | Удаление существующего товара | `200` |
| `DELETE` | `/products/999` | Удаление несуществующего товара | `200` |


Для негативных сценариев по очереди изменяется тип или удаляется одно из полей: `id`, `title`, `price`, `description`, `category`, `image`.

## Проверки корзин

Коллекция: `CartCollection`

| Метод | Endpoint | Сценарии | Ожидаемый статус |
|---|---|---|---:|
| `GET` | `/carts` | Получение списка всех корзин | `200` |
| `GET` | `/carts/1` | Получение первой корзины | `200` |
| `GET` | `/carts/7` | Получение последней корзины | `200` |
| `GET` | `/carts/999` | Получение несуществующей корзины | `200` |
| `POST` | `/carts/` | Создание корзины с корректными данными | `201` |
| `POST` | `/carts/` | Некорректный тип `products`, `userId` или `id` | `201` |
| `POST` | `/carts/` | Создание корзины без `products`, `userId` или `id` | `201` |
| `PUT` | `/carts/1` | Полная замена существующей корзины | `200` |
| `PUT` | `/carts/1` | Замена корзины пустым телом | `200`|
| `PUT` | `/carts/999` | Замена несуществующей корзины | `200` |
| `DELETE` | `/carts/1` | Удаление существующей корзины | `200` |
| `DELETE` | `/carts/-1` | Удаление несуществующей корзины | `200` |


## Используемые проверки Postman

В каждом запросе добавлен тест проверки HTTP-статуса ответа:

```javascript
pm.test("Status code is 200", function () {
		pm.response.to.have.status(200);
});
```
