# QA-test-task

Репозиторий предназначен для выполнения тестового задания по тестированию веб-приложения и API.

## Структура проекта

### Папка `reports`

- [frontend.md](reports/frontend.md) — чек-лист функционального тестирования полей формы и общих требований к интерфейсу.
- [backend.md](reports/backend.md) — описание API-проверок, выполненных в Postman.

### Папка `postman`

- [CartCollection.postman_collection.json](postman/CartCollection.postman_collection.json) — экспортированная из Postman коллекция для тестирования корзин.
- [ProductCollection.postman_collection.json](postman/ProductCollection.postman_collection.json) — экспортированная из Postman коллекция для тестирования товаров.
